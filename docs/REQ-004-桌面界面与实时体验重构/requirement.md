# REQ-004 桌面界面与实时体验重构

## 目标

在不改变 Linx68 设备协议和现有配置兼容性的前提下，落地 `docs/design` 中确认的桌面端 V1 设计，并同时解决 Codex 数据状态跳变、刷新等待偏长、网易云歌词偶发停留和天气定位反馈不清四类问题。持续增加不依赖新外部服务、具有明确设计语言的显示方案，并以真实程序、设备预览和自动化测试反复验证流畅度。

## 已确认决策

- D-01：桌面端采用单层一级侧栏，移除显示方案页内的第二层左侧分类栏；分类改为标题下方的横向标签。
- D-02：新增“数据服务”一级页面，集中展示 Codex、网易云、天气定位、设备连接的来源、状态、新鲜度和耗时；该页面只绑定共享状态，不重复发起数据读取。
- D-03：所有数据区域使用固定几何尺寸，并显式区分 `Loading`、`Ready`、`Empty`、`Stale`、`Error`；刷新时优先保留上一次有效内容。
- D-04：刷新采用独立数据源并行、最新请求优先和一次最终推送。快速切换方案时不得用上一个方案的数据快照绘制错误的中间帧。
- D-05：Codex 额度和任务共享读取生命周期，任务回退只读取日志尾部或增量内容；界面记录分项耗时，避免每次刷新全量扫描。
- D-06：网易云播放位置采用“会话基准位置 + 单调时钟”的有效播放时钟；检测到会话位置冻结时继续推进，切歌、暂停和拖动进度时重新校准。
- D-07：自动定位明确使用 Windows 系统定位，不伪装成 IP 定位；页面显示解析城市、权限或失败原因、手动城市回退，并提供重新定位。
- D-08：桌面应用和设备屏的日间/夜间设置保持独立。默认窗口 1280 × 800、最小窗口 1080 × 680 均需可用。
- D-09：新增“城市晨报”“今日节奏”“像素管家”三个方案，分别强化天气摘要、日/周进度和系统状态趣味表达，不新增外部账号或网络依赖。
- D-10：保留用户现有配置并为旧主题 ID 提供兼容迁移；本轮不改设备 HTTP 协议。
- D-11：页头以“预览更新”记录自动与手动预览；数据服务“刷新活动”单独记录“刷新全部”的时间和总耗时。自动预览可更新健康汇总，但不得覆盖全量刷新记录；失败时保留上次预览时间并标记失败。
- D-12：设备尚未尝试连接使用 `Empty`，实际推送失败使用 `Error` 并保留传输消息和耗时，后续推送成功恢复为 `Ready`；设备离线不影响本地预览。
- D-13：数据状态徽标和左侧状态条使用统一语义色：`Ready` 为绿色成功色，`Empty/Error` 为红色提醒，`Stale` 为黄色警告，`Loading` 使用强调色；浅色和深色模式含义一致。
- D-14：重建主题缩略图时保留用户正在浏览的分类；仅首次加载定位到当前主题分类，原分类已删除或为空时才回退，禁止异步重建把用户跳回“全部方案”或当前主题分类。
- D-15：Codex 额度与任务是两个可独立成功的子源；任意一个有有效数据时不得把整张卡投影为 `Empty`，应保留有效内容并标记部分陈旧。
- D-16：手动城市模式不请求 Windows 定位或反向解析；自动失败后显示“手动回退”实际来源；天气缓存只能在同一城市身份内降级，禁止跨城市展示旧天气。
- D-17：设备未配置或尚未尝试连接使用中性设备文案，不误报“离线”；数据总状态显示已就绪数量和空数据/问题数量，全空时不宣称正常。
- D-18：主工作区使用克制的明暗环境光渐变，数据卡保持纯色和固定几何；新增“磁带余晖”与“信号花园”，内置方案总数为 15。

## 性能预算

- 有缓存时切换显示方案：150 ms 内出现正确方案预览状态，不显示其他方案的旧帧。
- 手动刷新：100 ms 内显示稳定的刷新反馈；各数据源并行执行，单个慢源不阻止其他卡片更新状态。
- 音乐播放中的歌词检查：正常刷新周期内保持前进；原始会话位置连续冻结 2 次后启用推算位置。
- 回退日志读取：每个文件仅检查有限尾部，不从头扫描完整 rollout。
- 一次刷新只推送一个最终设备帧；用户再次刷新或切换方案时，旧请求结果不得覆盖新请求。
- 成功刷新完成后，页头活动时间在同一 UI 调度周期内更新；后台定时刷新不能长期遗留旧时间。
- 设备连接失败后至少退避 5 秒再自动重试；数据服务页显示最近一次推送耗时，不因离线阻塞本地数据刷新。
- 手动城市刷新时 Windows 定位调用次数为 0；新城市请求失败时不展示其他城市的缓存帧。

## 验收

- 显示方案、数据服务、自动化、外观、其他设置和关于六个一级入口均可正常导航，核心四页与设计稿的信息层级一致。
- Codex 额度或任务首次加载、成功、无数据、陈旧和失败时，卡片位置、预览尺寸和主要操作不发生跳动。
- 快速切换方案、反复刷新和切换日夜模式时，不出现旧主题覆盖新主题、重复推送或界面失去响应。
- 自动刷新开启时，页头“预览更新”时间随成功刷新前进；失败时显示上次预览时间，恢复后重新显示最新时间；全量数据源耗时不被后台预览覆盖。
- 设备连接未尝试、推送超时或失败、成功恢复三种状态可区分；失败原因和耗时在数据服务页可见。
- 数据状态卡在浅色与深色模式下同时显示来源、详情和耗时，状态颜色可区分且不改变卡片几何尺寸。
- 数据卡 `Empty/Error` 明确显示红色，`Ready` 明确显示绿色；真实网易云媒体会话可从红色空态恢复为绿色正常态并显示曲目、艺人和歌词状态。
- 在外观、字体或设备屏日夜模式触发缩略图重建时，当前分类和可见方案列表保持不变；选中主题身份仍正确。
- 网易云连续播放、暂停、继续、拖动进度和切歌后，歌词均能重新同步；无逐字歌词时继续使用逐行歌词降级。
- 天气页明确显示 Windows 定位或手动城市来源，自动定位失败时可理解、可重试、可切换手动城市。
- 五个特色方案在日间和夜间均可渲染为 142 × 428 JPEG，且不超过设备文件大小限制。
- `dotnet build`、Core Smoke、UI Smoke 全部通过；在 1280 × 800 和 1080 × 680 下运行真实程序并检查核心页面和连续交互。

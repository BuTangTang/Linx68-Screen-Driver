# M10 城市选择与位置身份

## I0 正确性与隐私

- [x] 手动城市执行“刷新全部”时不调用 Windows 定位或 BigDataCloud。
- [x] 自动定位失败但手动城市天气成功时，显示“手动回退”实际来源。
- [x] Open-Meteo 缓存按城市身份隔离；北京成功后切北海失败，不得展示北京天气。
- [x] 反向解析失败不伪装为 `Ready · 当前位置`；保留坐标时使用 `Stale` 并显示城市解析失败。
- [x] 切换到手动城市时立即失效进程内自动位置缓存；城市级反向解析坐标降为 3 位小数。
- [x] 定位缓存使用代际锁，失效后的旧请求不能复活缓存；城市解析失败 45 秒后允许恢复重试。
- [x] “北海”等中文城市先取多候选并回查“北海市”，优先中国行政城市；真实验证返回广西北海市，不再误选北海槟城。
- [ ] 进一步区分权限拒绝、系统位置服务关闭、超时与网络失败。
- [ ] 空手动城市不再静默伪装为北京；已有北京配置继续兼容。

## I1 城市选择交互

- [ ] 手动城市改为搜索候选，候选显示城市、行政区、国家并解决“朝阳”等歧义。
- [ ] 输入至少 2 字且 300 ms 防抖，只在用户确认候选后保存、刷新和推送。
- [ ] 本地保留最近 5 个手动城市，不持久化自动定位精确坐标。

## I2 取消、性能与真实验收

- [x] 重新定位与刷新全部 single-flight；模式切换和现有城市输入遵循 latest-request-wins。
- [ ] 候选城市确认接入同一 latest-request-wins 管道，只允许已确认候选保存和推送。
- [ ] 城市搜索缓存命中 <200 ms，网络目标 <800 ms，硬超时 2 s；手动天气硬超时 5 s。
- [ ] 实测北海、南宁、盐城与自动定位的 Ready/Empty/Stale/Error/Recovery 桌面卡和设备帧。

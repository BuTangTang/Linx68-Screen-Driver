# M19 删除股票功能

## 目标

彻底移除股票主题、设置和 Yahoo Finance 数据请求，避免继续保留不可维护的数据入口。

## 实施

- 删除股票主题、设置/快照模型、应用端数据源接口与基础设施实现。
- 清除主窗口的股票设置卡、状态更新与首次提示，并移除依赖注入注册。
- 将设置版本升级到 8，把旧 `stocks` 主题迁移为 `clock-dot-matrix`；历史 `Stocks` JSON 字段在保存后不再输出。
- 同步更新核心/UI 烟雾测试、隐私与便携版说明、架构和发布说明。

## 验收

- 内置主题目录和桌面设置页没有股票入口。
- 不再存在 Yahoo Finance 请求或股票数据接口。
- 旧配置可正常加载并回退到点阵时钟，重新保存后没有 `Stocks` 字段。

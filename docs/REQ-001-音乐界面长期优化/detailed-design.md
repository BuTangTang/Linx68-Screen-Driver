# REQ-001 详细设计

## 1. 音乐时间轴与歌词刷新

### 数据流

```text
WindowsMusicSnapshotSource
  -> MusicSnapshot(Position)
  -> DashboardRefreshService
  -> DashboardSnapshotBuilder（封面与歌词缓存）
  -> IScreenTheme.Draw
  -> ScreenRenderer / Device Push
```

歌词文本可缓存 12 小时，但 `MusicSnapshot.Position` 不可缓存。每次刷新都以当前快照的位置调用 `LyricsSnapshot.FindAt`，因此同一份歌词数据也会随播放位置产生新的当前行和下一行。

### 回退时间轴

当网易云没有提供 Windows 媒体时间轴时，`WindowsMusicSnapshotSource` 对相同的“曲名 + 歌手”维持单一播放时钟；只有曲目键变化时重置。时钟必须使用单调的经过时间，避免系统时钟调整导致歌词倒退或冻结。若 Windows 媒体会话提供了正式时间轴，仍以该时间轴为准。

### 自动主题规则

- `AutoSwitchToMusic=true` 且当前选择不是音乐分类：播放时临时进入基础音乐主题。
- 音乐分类仅有“封面歌词”主题：播放时保持该主题。
- 用户手动选择非音乐主题：关闭 `AutoSwitchToMusic`，让手动选择优先。

## 2. 142×428 音乐屏幕设计

所有音乐主题沿用同一信息优先级：

1. 顶部 20px：播放状态、来源。
2. 中部：封面或歌词焦点，最多一个主视觉。
3. 曲目信息：曲名优先于歌手。
4. 底部：当前歌词、下一句、进度和时间。

| 方案 | 主视觉 | 歌词布局 | 使用场景 |
| --- | --- | --- | --- |
| 封面歌词 | 方形封面、专辑色彩背景 | 上一句 + 当前句 + 下一句 | 唯一默认方案，信息均衡 |

颜色采用深色底、主题强调色和至少一档浅色文本；所有内容基于 `SafeBounds` 定位，不能依赖固定绝对坐标。

## 3. 桌面主题选择页

音乐分类不新增页面或复杂配置：保持左侧分类和右侧画廊结构。仅保留一张“封面歌词”主题卡，其名称、用途和选中态必须清晰；不显示额外音乐变体，避免影响其他分类的筛选与响应式宽度计算。卡片说明使用可在一行读完的短文案，避免出现“下一 / 句”这种孤行单字。

右侧预览在窗口最小高度下以等比缩放优先：设备模拟框的自然尺寸为 154×440，若中间可用行不足则只缩小、不放大；摘要保持在底部，设备边框、底部进度和摘要不得被裁切。

分类切换以 `ThemeGroupViewModel.Id` 为唯一键：点击分类后，恰好一个左侧分类处于选中态，`VisibleThemes` 必须仅包含该分类，顶部 `VisibleThemeCountText` 必须使用同一分类的显示名和数量；点击“全部方案”后恢复全量列表且清除各分类选中态。

`DevicePreviewControl` 在 `FrameSource=null` 时，保留现有设备边框与状态遮罩，但在屏幕中央绘制低干扰的“等待预览数据”文字。收到首帧后直接绘制图片，不增加动画、缓存或设备端数据；该占位仅在 WPF 桌面预览中渲染。

### 自动化页收敛

音乐分类只剩“封面歌词”后，播放/暂停分别选择媒体主题不再提供有效选择，因此自动化页不再渲染“媒体主题自动切换”卡片及其两个下拉框。保留 `AutoSwitchToMusic`，并且无论当前选中何种方案都始终显示；其展示名称和说明固定为“播放音乐时自动切换”和“检测到媒体播放时显示封面歌词”。用户手动选择非音乐方案时，既有的自动关闭规则不变。

历史配置中可能存在的旧媒体方案字段继续由设置反序列化层忽略或迁移，不要求用户手工清理；桌面 UI 和运行时选主题逻辑均不得读取它们。

### 额度主题的平台标识

`AiQuotaTheme` 以 `AiQuotaSnapshot.PlatformName` 作为设备帧的单一平台标识来源。顶部标题组合为“{平台名} 额度”，能在默认 `Codex` 快照下明确呈现“Codex 额度”；中部主标签复用同一个平台名。`SystemSnapshot.DesignSample` 也使用 `Codex`，使主题卡和导出的验收样图与默认产品配置一致。

平台名仍可由设置页的“屏幕显示名称”覆盖，且 MiMo 等非 Codex 来源保持自己的名称；不以渲染层的硬编码替代真实来源、用户名称或 Codex 的 ChatGPT 登录说明。

### 真实音乐帧验收

烟雾测试提供 `--music-preview <输出路径>`。该命令读取一次当前 `WindowsMusicSnapshotSource` 快照；若快照来自网易云，则复用 `NetEaseMusicSnapshotEnricher` 和 `NetEaseLyricsSnapshotSource` 补齐封面与同步歌词。随后使用现有 `MusicTheme` 与 `ScreenRenderer` 输出标准 142×428 JPEG。`--music-motion-preview <输出目录>` 在同一个媒体源中读取首句时间戳，再等待到首句开始后、间隔四秒取得两份快照；命令要求同曲目位置递增，并导出两张帧验证歌词与动效刷新。命令不写入设置、不推送设备，也不在没有可用媒体会话时伪造成功。

### 长歌名的稳定单行

`ScreenCanvas` 提供按实际 `FormattedText` 宽度选择字号的单行绘制能力。`MusicTheme` 的曲名先使用 14px；若超过安全区宽度，按 0.5px 递减至 11px，再交给现有字符省略机制处理最终极端长文本。歌手、歌词卡与进度区的纵向坐标不变，因此每次音乐刷新都保持稳定，且不增加滚动状态或计时器。

### 同步歌词首句预告

`LyricsSnapshot.FindAt` 返回 `current=null`、`next=首句` 时，说明同步歌词已成功获得但首条尚未开始。`MusicTheme` 此时将歌词卡标签改为“即将开始”，把首句以当前歌词的主字号显示，并清空第二行；无可用歌词时仍显示“正在查找同步歌词”。该分支只改变展示文本，不改变播放位置、歌词偏移或时间轴。

### 网易云开头制作署名过滤

`NetEaseLyricsSnapshotSource` 在解析 LRC 后只检查连续的开头行。若文本去除空白后带冒号，且标签包含作词、作曲、编曲、制作、监制、演唱、和声、人声、混音、母带、录音、封面、统筹、企划、发行、出品、美术或设计等制作职能关键词，则丢弃该行；遇到第一个非署名行即停止过滤。过滤为空时按既有不可用结果进入 LRCLIB 回退；不改变 LRC 解析器、歌词时间戳或其他平台数据源。

### 封面降级与连续歌词

`MusicTheme` 先尝试解码媒体会话提供的封面。缺失或解码异常时，背景和封面区域都使用稳定的深青色渐变；封面框内绘制音乐符号与简化波形，不显示“音乐”等纯文字占位。正常封面仍使用原有全屏封面背景与方形封面，避免改变已取得封面时的视觉风格。

`LyricsSnapshot` 增加同一播放位置的上一句、当前句、下一句查询；既有 `FindAt` 保持可用，继续返回当前/下一句。音乐页底部歌词卡扩大为 100px：上一句使用弱化小字，当前句使用 18px 高对比字、可占两行，下一句使用强调色单行提示。三行固定占位，不随前后句存在与否改变坐标。首句开始前将首句放入当前大歌词位、标签显示“即将开始”；无歌词时保留“正在查找同步歌词”。进度条与时间仍位于歌词卡下方。

### 播放位置驱动的歌词微动效

设备只接收周期性 JPEG，不能依赖桌面 UI 的连续动画。`MusicTheme` 因此只从当前 `MusicSnapshot.Position` 计算视觉相位：歌词卡左侧的进度点在当前行到下一行的时间区间内向下移动，边框以低幅度强调色呼吸，右上角三段小波形随相位改变高度。暂停时波形和进度点不再变化。动效不改变文本的横纵坐标，不引入跑马灯，也不声称具备没有数据支撑的逐字高亮。

## 4. 测试设计

- 为连续音乐快照添加同一实例、不同时间点的位置递增断言。
- 为两条不同时间戳歌词渲染两个帧，断言帧字节不相同。
- 为自动切换添加“唯一音乐方案保持不变”的应用服务断言。
- 为 UI 主题页添加音乐分类方案数、选中态和卡片可读性断言。
- 为 1080×680 紧凑窗口添加完整预览缩放与摘要可见性断言。
- 为全部方案分类添加逐项点击、左侧标签可见、标题/计数/卡片同步的断言。
- 为无 `FrameSource` 的设备预览添加中心占位像素断言，确保启动时不是纯黑屏。
- 为自动化页添加回归：音乐自动切换卡与开关存在、说明包含“封面歌词”，旧媒体主题自动切换卡不存在。
- 为额度主题添加默认 Codex 样本断言，并用另一平台名渲染对照帧，确认平台标识实际进入设备画面。
- 为真实音乐帧导出添加会话可用、JPEG 尺寸和输出文件断言；人工检查导出图的歌曲、歌词、封面和进度布局。
- 为长歌名快照渲染单独的音乐帧，确认标题自适应后的设备 JPEG 仍合规，并和短歌名帧共同覆盖原有布局。
- 为首句未来时刻的同步歌词渲染预告帧，确认其与无歌词帧不相同且仍符合设备 JPEG 限制。
- 为网易云模拟响应加入连续开头署名、第一句正式歌词和后续署名文本，验证只剔除开头署名且正式歌词顺序不变。
- 为无封面与损坏封面字节分别渲染，验证绘制不会失败且输出保持合规；为歌词上下文增加上一句断言，并渲染两行当前歌词的帧，确认其与无歌词帧不同且不会超出 JPEG 限制。`--music-design-preview <输出路径>` 导出该确定性帧，供小屏视觉验收。
- 为同一当前歌词的两个不同位置渲染帧，断言活动指示器使 JPEG 不同；暂停快照保持静态布局。

# REQ-001 音乐界面长期优化

## 目标

在不改变设备传输、天气、Codex 用量和非音乐方案行为的前提下，持续优化音乐显示与主题选择体验：歌词必须随着同一首歌的播放位置逐行变化，音乐主题必须有清晰的视觉层级，桌面端主题选择必须能清楚辨识音乐方案与当前选中状态。

## 已确认决策

- D-01：用户要求先完成设计，再按设计实现。
- D-02：自动播放切换不能覆盖用户手动选择的音乐展示方案。
- D-03：歌词和封面优先使用 Windows 媒体会话；网易云未公开封面时允许使用已存在的网易云元数据回退。
- D-04：持续迭代从当前时间执行至 2026-08-09 06:00（Asia/Shanghai）；不擅自提交或推送。
- D-05：只修改音乐数据、音乐主题、主题选择界面和对应测试；不修改设备协议、外部服务凭据或其他数据源。
- D-06：音乐分类只保留用户确认的“封面歌词”方案；不再展示封面聚焦、歌词沉浸或律动播放器等额外变体，避免无用选择。
- D-07：在最小窗口尺寸 1080×680 及以上，右侧设备预览必须完整等比显示；方案卡说明使用不产生孤行单字的短文案。
- D-08：点击任一方案分类后，左侧分类标签、顶部方案标题与可见主题卡必须保持同一分类状态；分类切换不能导致左侧标签消失。
- D-09：桌面预览在首帧尚未到达时必须显示“等待预览数据”占位，而非纯黑屏；占位只作用于桌面端，不改变设备传输帧。
- D-10：自动化页不保留“媒体主题自动切换”及播放/暂停分别选方案的冗余配置；只保留一个始终可见的“播放音乐时自动切换”开关，且文案明确其唯一目标为显示“封面歌词”。
- D-11：额度主题在设备屏幕、主题卡预览和验收样图中必须使用当前平台名；默认 Codex 数据源显示“Codex 额度”，但不覆盖用户为其他来源设置的显示名。
- D-12：音乐视觉验收必须支持导出当前本机媒体会话的真实设备帧；导出前使用现有网易云封面/歌词补齐链路，不引入新数据源或改变播放数据。
- D-13：长歌名在固定单行内优先按实际文字宽度由 14px 缩小至最低 11px，仍放不下才省略；不使用跑马灯或会随刷新跳动的动画。
- D-14：已取得同步歌词但播放位置早于第一条时间戳时，歌词卡显示“即将开始”和首句，不显示泛化的“正在查找同步歌词”；进入第一条后恢复当前/下一句双行。
- D-15：网易云 LRC 在正式歌词前的“作词 / 作曲 / 人声处理”等带冒号制作署名行不作为歌词显示；首条非署名歌词出现后不继续过滤，过滤后无内容时沿用既有 LRCLIB 回退。
- D-16：封面字节缺失或无法解码时，音乐页以统一的音乐符号渐变占位替代空白或纯文字；歌词区改为上一句、当前大歌词（最多两行）和下一句的连续层级，首句开始前仍显示“即将开始”。
- D-17：设备端以周期性 JPEG 帧刷新，歌词动效必须由真实播放位置驱动：显示低干扰的歌词进度点、呼吸边框和小波形；不使用跑马灯、文字位移或需要逐字时间戳的伪逐字歌词。
- D-18：用户选择升级 Codex 额度界面为“额度圆环 + 重置卡 + 剩余信息卡”；只使用已有的可用百分比、剩余次数、额度周期与重置时间，不伪造日用量历史、消费趋势或“偏低”等派生状态。
- D-19：按用户要求彻底删除股票功能，包括主题、设置、Yahoo Finance 数据源、提示和测试；旧配置选择 `stocks` 时迁移到“点阵时钟”，历史 `Stocks` 字段在下次保存时移除。

## 用户可见结果

1. 在同一首网易云歌曲连续播放时，2 秒内取得的两个快照必须有递增的播放位置；跨越歌词时间戳后，渲染图中的当前歌词必须变化。
2. 音乐分类只展示并使用“封面歌词”；播放自动切换始终进入该方案，不出现额外音乐变体入口。
3. 基础音乐主题需在 142×428 屏幕上同时呈现：播放状态、封面、曲名、歌手、上一句、当前歌词、下一句、进度和时间；文字不能与屏幕安全区或状态遮罩重叠。
4. 桌面主题选择页需让音乐方案的名称、用途和选中态清楚可分，并保持其它分类与原有导航行为不变。
5. 运行预览和实机推送仍使用 512KB 内的 JPEG。
6. 在 1080×680 紧凑窗口中，完整设备边框、底部进度与“当前方案”摘要均必须可见，不允许裁切。
7. 在“电脑监控、时间与天气、Codex 信息、音乐播放、点阵风格、全部方案”之间切换时，左侧标签、顶部计数和可见卡片必须同步更新。
8. 程序启动或刷新期间未取得预览帧时，设备模型中央可见“等待预览数据”；首帧到达后占位立即消失。
9. 无论当前选中何种方案，自动化页只展示定时推送和“播放音乐时自动切换”两项；不展示媒体播放/暂停主题下拉框，开关说明明确写出会显示“封面歌词”。
10. 使用默认配置时，额度设备帧顶部与主标题均清晰标示 Codex；同一渲染器在其他平台名下使用对应平台名，不能把其他来源误标为 Codex。
11. 本机存在可用媒体会话时，可导出一张真实曲目、封面和同步歌词组成的 142×428 JPEG，用于验收实际小屏可读性。
12. 长歌名在不挤压歌手、歌词、进度的前提下尽可能完整显示；短歌名保持现有较醒目的 14px 样式。
13. 在同步歌词首句开始前，设备屏幕明确提示“即将开始”并展示首句；不能把首句误标为“当前歌词”，也不能出现重复的下一句。
14. 歌曲开头不将“作词：”“作曲：”等制作署名显示为当前或下一句歌词；第一句正式歌词及后续歌词保持原样。
15. 封面缺失或损坏时，音乐页仍显示有辨识度的音乐占位图；正常播放时显示上一句淡化文字、最多两行的当前歌词与下一句提示，三者均不与进度或曲目信息重叠。
16. 正在播放时，同一条歌词内的设备帧能随播放位置呈现可读的微动效；暂停后动效停留在稳定状态，歌词文本不滚动、不闪烁。
17. 默认 Codex 数据在 142×428 屏幕上以圆环展示可用百分比，下方清晰展示下一次重置、额度类型与剩余次数；不显示“偏低”等派生状态，更换平台名时仍显示实际平台，而非硬编码 Codex。
18. 股票不再出现在主题选择、设置页、关于页、便携版说明或运行时数据请求中；已选股票主题的旧配置启动后自动回退到点阵时钟。

## 验收证据

- `dotnet build Linx68.ScreenDriver.sln --configuration Release --no-restore`：0 warning、0 error。
- 核心烟雾测试：音乐快照时间轴、歌词行切换、主题解析、渲染尺寸和 JPEG 限制全部通过。
- UI 烟雾测试：全部方案分类切换、音乐分类、手动选中优先级和主题卡布局通过。
- 在本机网易云播放状态运行 `--music-probe`：`position-advanced=True`、`artwork=True`、`lyrics=True`。
- 导出主题预览并人工检查“封面歌词”方案的文字层级、边距和视觉效果。
- 在 1080×680 的深色与浅色渲染中，确认设备预览等比缩小且设备边框、进度和当前方案摘要均完整可见。
- UI 烟雾测试：自动化页只保留音乐自动切换开关；旧媒体主题自动切换配置不存在，且开关文案标明“封面歌词”。
- 导出默认额度设备帧并人工检查“Codex 额度”标题与主标签；回归测试验证更换平台名会得到不同的额度帧。
- 运行真实音乐帧导出命令；断言会话可用、设备 JPEG 尺寸合规，并人工检查曲名、歌手、歌词和进度互不遮挡。
- 使用长歌名快照渲染音乐帧；确认帧仍符合设备 JPEG 限制，人工确认标题未造成相邻信息重叠。
- 使用位置早于首条时间戳的同步歌词快照渲染帧；验证预告状态与无歌词状态有不同视觉输出，并人工检查首句布局。
- 使用带开头制作署名和正式歌词的网易云 LRC 响应；验证署名被过滤、后续正式歌词保留，并在真实设备帧中检查歌词卡。
- 使用空封面与无效封面字节分别渲染音乐帧，验证均能稳定输出设备 JPEG；使用三行同步歌词渲染，验证上一句、当前句和下一句的时间轴上下文正确，并人工检查连续歌词布局。
- 使用同一当前歌词的两个不同播放位置渲染设备帧，验证歌词活动指示器发生变化；人工检查动效不遮挡歌词与进度。
- 导出 Codex 和非 Codex 的额度设备帧，人工检查圆环、重置卡、剩余信息卡互不遮挡；回归验证两帧不同且 JPEG 合规。
- 核心烟雾测试验证主题目录不含 `stocks`、旧配置能够迁移到 `clock-dot-matrix`、保存后的 JSON 不再包含 `Stocks`；UI 烟雾测试验证保留的额度提示窗口几何正常。

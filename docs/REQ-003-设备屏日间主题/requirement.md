# REQ-003 设备屏日间主题

## 目标

为 Linx68 设备屏增加全局可选择的日间/夜间外观，解决现有内置方案以黑色或深色背景为主、强光环境下视觉单一的问题。

## 已确认决策

- D-01：日间/夜间是设备屏全局外观，不复制成两套主题卡；任意保留方案都可切换两种外观。
- D-02：删除状态极简、极简时钟、霓虹时钟、点阵时钟、点阵时钟天气和图片时间；旧设置选择这些 ID 时自动迁移到时钟天气。
- D-03：保留时钟天气；删除重复的 Codex 信息组合方案，Codex 额度和 Codex 任务作为两个独立大字方案。
- D-04：日间基调采用暖白底、深灰正文、雾灰分隔线和珊瑚橙强调色；夜间保留深色信息层级。
- D-05：每个主题继续遵守 142 x 428 设备画面、安全区和 512 KB JPEG 上限。

## 验收

- 显示方案库仅保留 10 个已确认方案，且不再显示已删除方案。
- 外观页可选择设备屏“日间”或“夜间”，切换后立即重新渲染和推送当前方案。
- 日间版所有保留方案使用白色或近白背景；夜间版使用深色背景。时钟天气、Codex 额度和 Codex 任务在两种外观下都可渲染。
- 状态、音乐、Codex 额度和 Codex 任务在无可选数据时仍可渲染；时钟天气复用天气等待数据状态。
- 全部内置主题可渲染为 142 x 428 JPEG，且不超过设备文件大小限制。
